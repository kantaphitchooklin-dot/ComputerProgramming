# Week 6 — Nested Loops & Pattern Generation

## 📌 Overview

Week 6 focuses on nested loops and algorithmic problem solving.

The exercises demonstrate how multiple loops can be combined to generate patterns, construct tables, process repeated data, and search for mathematical solutions.

---

## 📂 Exercises

### 6.1 — Isosceles Triangle

The program generates an isosceles triangle using `*`.

The number of rows is determined by user input.

The program uses two inner loops:
- One loop prints spaces
- One loop prints `*`

The number of stars follows:

`2 × i - 1`

### Concepts
- Nested loops
- Pattern generation
- Spacing
- Mathematical expressions

---

### 6.2 — Number Pattern

The program receives a number from 1–20 and generates a square-like output containing numbers from 9 down to 1 repeatedly.

When the value reaches 1, it starts again from 9.

### Concepts
- Nested loops
- `while`
- Loop counters
- Modular/repeating sequences
- Input validation

---

### 6.3 — Hexadecimal Pattern

The program receives a value from 1–16 and generates a rectangular pattern using hexadecimal representation.

The `%X` format specifier is used to display values in hexadecimal.

### Concepts
- Nested loops
- Hexadecimal numbers
- `%X`
- Pattern generation
- Range validation

---

### 6.4 — Number Matrix

The program creates an `n × n` number pattern.

The value is generated using:

`(i + j) % n + 1`

This creates a repeating sequence across rows and columns.

### Concepts
- Nested loops
- Mathematical patterns
- Modulo operator
- Matrix-like output

---

### 6.5 — Find Solutions of a²b = n

The program searches for values of `a` and `b` that satisfy:

`a × a × b = n`

It checks possible values using nested loops and reports every valid `(a,b)` pair.

### Concepts
- Nested loops
- Brute-force search
- Mathematical equations
- Conditional checking
- Counting solutions

---

## 🧠 Skills Learned

- Nested loops
- Pattern generation
- Mathematical algorithms
- Brute-force searching
- Matrix-like processing
- Hexadecimal representation
- Input validation

## 🎯 Learning Outcome

Week 6 improves algorithmic thinking by requiring multiple loops and mathematical conditions to work together to produce structured output and search for solutions.
