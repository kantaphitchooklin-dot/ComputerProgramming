# Week 8 — Arrays, 2D Arrays & Structures

## 📌 Overview

Week 8 introduces data structures commonly used in C programming, including one-dimensional arrays, two-dimensional arrays, and structures.

The exercises focus on storing, searching, sorting, and analyzing multiple pieces of data.

---

## 📂 Exercises

### 8.1 — Ascending Sort

The program receives 10 integers and sorts them from smallest to largest.

The program compares pairs of elements and swaps their positions when they are in the wrong order.

### Concepts
- One-dimensional arrays
- Nested loops
- Sorting
- Swapping values
- Temporary variables

---

### 8.2 — Search in 2D Array

The program stores values in an `8 × 10` two-dimensional array.

The user enters a value, and the program searches the entire array.

If the value exists, the program displays every `(row, column)` position where it occurs.

### Concepts
- Two-dimensional arrays
- Nested loops
- Linear search
- Row/column indexing
- Search algorithms

---

### 8.2.1 — Maximum Difference Between Adjacent Values

The program receives 10 integers and calculates the largest absolute difference between adjacent elements.

For example, it compares:

`arr[0]` with `arr[1]`

`arr[1]` with `arr[2]`

and continues until the end of the array.

### Concepts
- Arrays
- Adjacent element comparison
- Absolute difference
- Loop processing
- Maximum value tracking

---

### 8.3 — Maximum Adjacent Difference

This exercise solves the same general problem as 8.2.1 using a different implementation.

The difference is calculated and converted to a positive value when necessary.

### Concepts
- Arrays
- Loops
- Absolute value logic
- Maximum tracking
- `#define`

---

### 8.4 — Student Structure Array

The program stores information for 10 students using a structure containing:

- Student ID
- Name
- Score

It then calculates:

- Average score
- Minimum score
- Maximum score

### Concepts
- `struct`
- Array of structures
- Data organization
- Average calculation
- Min/Max searching

---

### 8.5 — Find Students With Maximum Score

This program stores information about 10 students and finds the highest score.

It then counts how many students achieved that score and displays their information.

### Concepts
- Structures
- Array of structures
- Searching
- Counting
- Multiple-pass data processing

---

## 🧠 Skills Learned

- Structures
