# Week 4 — Conditional Statements & Decision Making

## 📌 Overview

Week 4 focuses on decision-making in C programming.

The exercises introduce conditional statements that allow a program to make different decisions depending on user input.

---

## 📂 Exercises

### EX4_01 — Maximum & Minimum

This program receives two integers and determines which number is the maximum and which is the minimum.

It also checks whether the input values are within the range 1–100 and handles the case where both values are equal.

### Concepts
- `if`
- `else if`
- `else`
- Comparison operators
- Logical OR `||`
- Input validation

---

### EX4_02 — Check Alphabet A

The program receives one character and checks whether it is the uppercase letter `A`.

### Concepts
- Character comparison
- `if/else`
- `char`

---

### EX4_03 — Check Alphabet B

This program checks whether the input character is either uppercase `B` or lowercase `b`.

### Concepts
- Character comparison
- Logical OR `||`
- Conditional statements

---

### EX4_04 — Sum & Even/Odd

The program receives three integers, calculates their total, and determines whether the result is even or odd.

The program uses:

`sum % 2`

to determine whether the result is divisible by 2.

### Concepts
- Arithmetic operators
- Modulo `%`
- Even/Odd checking
- `if/else`

---

### EX4_05 — Simple Calculator

This program implements a calculator using four operations:

- `A` → Addition
- `B` → Subtraction
- `C` → Multiplication
- `D` → Division

The program also determines the larger and smaller number before performing the calculation.

Division by zero is checked before performing division.

### Concepts
- `switch`
- `case`
- `break`
- Ternary operator `?:`
- Conditional statements
- Input validation
- Error handling

---

## 🧠 Skills Learned

- Conditional statements
- Logical operators
- Comparison operators
- Modulo operations
- `switch-case`
- Ternary operators
- Input validation
- Basic error handling

## 🎯 Learning Outcome

Week 4 demonstrates how programs can make decisions based on input and conditions, forming an important foundation for more complex algorithms.
