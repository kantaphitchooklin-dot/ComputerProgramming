# Week 5 — Loops, Strings & Repetition

## 📌 Overview

Week 5 introduces repetitive programming using loops.

The exercises demonstrate how `for` and `while` loops can automate repeated calculations, process strings character by character, and generate repeated output.

---

## 📂 Exercises

### EX5_01 — Repeated Addition

The program receives a number and a count, then adds the same number repeatedly.

For example:

`5 + 5 + 5 = 15`

The program uses a `for` loop to perform the repeated addition.

### Concepts
- `for` loop
- Accumulator variable
- Repetition
- Arithmetic operations

---

### EX5_02 — Reverse Name

The program receives a name, determines its length, and prints the characters in reverse order.

Each character is converted to uppercase using `toupper()`.

### Concepts
- Character arrays
- `while` loop
- `for` loop
- String length
- `<ctype.h>`
- `toupper()`

---

### EX5_03 — Convert String to Lowercase

The program receives a string and converts uppercase English letters into lowercase letters.

The program checks whether each character is between `A` and `Z`.

### Concepts
- String processing
- `while` loop
- Character comparison
- ASCII-based conversion
- Character arrays

---

### EX5_04 — Summation Between Two Numbers

The program receives two integers and finds the smaller and larger values.

It then calculates the sum of every integer between them.

Example:

`2 + 3 + 4 + 5 = 14`

### Concepts
- `for` loop
- Accumulator
- Range processing
- Comparison
- Arithmetic operations

---

### EX5_05 — Repeated Message

The program receives a positive integer and prints:

`I Miss You`

the specified number of times.

If the input is zero or negative, it displays an alternative message.

### Concepts
- `for` loop
- Conditional statements
- Repeated output
- Input validation

---

## 🧠 Skills Learned

- `for` loops
- `while` loops
- Loop counters
- Accumulator variables
- String processing
- Character manipulation
- Repetitive calculations
- Input validation

## 🎯 Learning Outcome

This week develops the ability to automate repetitive tasks using loops and process strings one character at a time.
